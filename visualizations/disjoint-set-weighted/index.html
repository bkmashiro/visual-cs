How Weighted Union-Find Works

The Weighted Union-Find (Weighted Quick Union) augments each parent pointer with a multiplicative edge weight. If weight[x] = w, then value(x) = w × value(parent[x]). This lets us answer ratio queries — "what is value(a) / value(b)?" — in nearly O(1) amortised time.

  • Union(a, b, w) — declare that value(a) / value(b) = w. Internally: find the roots of both, decide attachment order by rank, then set the new edge weight so all existing weight invariants stay consistent.
  • Find(x) — walk to the root accumulating the product of edge weights. Path compression rewires each visited node directly to the root and multiplies its weight to the accumulated product.
  • Ratio(a, b) — run Find on both; if they share a root, the answer is wt(a) / wt(b). Otherwise "unrelated".
  • Union by rank keeps the tree height O(log n), and path compression flattens paths after traversal so future queries are faster.

Classic application: the weighted liquid containers problem — "container A holds 2× as much as B, B holds 3× as much as C; how much more than C does A hold?"
