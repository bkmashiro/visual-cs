Pseudocode
inside ← 0
for i = 1 to N:
  x ← random(-1, 1)
  y ← random(-1, 1)
  if x²+y² ≤ 1:
    inside += 1
  π ≈ 4 × inside / i
Key Insight

A unit circle has area π. The enclosing 2×2 square has area 4. So:

π ≈ 4 × (hits / total)

By the Law of Large Numbers, this converges to the true π as N → ∞. Error shrinks as O(1/√N) — very slowly! You need ~1M points for 3 correct decimal places.
