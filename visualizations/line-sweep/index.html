Algorithm

The sweep line moves left → right. Three event types drive updates to the status structure:

L Left endpoint → insert segment, check neighbors.
R Right endpoint → remove segment, check new neighbors.
X Intersection → swap two segments, check outer neighbors.

Complexity: O((n+k) log n) — n segments, k intersections found.
