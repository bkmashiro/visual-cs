🧠 How It Works

A Count-Min Sketch uses a 2D counter array of d rows × w columns and d independent hash functions.

Add(key, Δ): For each row i, compute column j = hᵢ(key) mod w and increment table[i][j] += Δ.

Query(key): For each row i, look up table[i][hᵢ(key)]. Return the minimum across all rows.

Hash collisions can only add to a counter, never subtract — so the sketch never underestimates. The min across rows filters out most collision noise.

📐 Error Guarantee

With w = ⌈e/ε⌉ columns and d = ⌈ln(1/δ)⌉ rows:

The estimate f̂ satisfies f ≤ f̂ ≤ f + εN with probability ≥ 1−δ

where f is the true count and N is the total count of all items added.
