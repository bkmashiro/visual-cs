van Emde Boas — Predecessor & Successor in O(log log U)

A vEB tree on universe U = {0,…,U−1} answers predecessor/successor queries in O(log log U) by recursively halving the effective universe at each level.

high(x) = ⌊x / √U⌋ → cluster index (0 … √U−1) low(x) = x mod √U → offset in cluster (0 … √U−1) index(i, j) = i · √U + j → reconstruct from cluster i, offset j Successor(x): 1. x < min(V) → return min(V) — O(1) 2. low(x) < max(cluster[high(x)]) → recurse into cluster[high(x)] 3. otherwise → c = summary.successor(high(x)) return index(c, min(cluster[c]))

Each recursive call replaces U with √U, so the depth is log log U. With U=16: 2 levels. With U=64: 3 levels. With U=65536: only 4 levels.

  • Insert / Delete: O(log log U) — update cluster and possibly summary
  • Min / Max: O(1) — stored directly at the root node
  • Space: O(U) total across all recursive sub-trees
  • Key trick: min is not stored in a cluster — it's kept separate, so inserting a new min touches only the root in O(1)
