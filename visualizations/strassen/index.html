Pseudocode
Strassen(A, B):
  // 7 multiplications
  M₁ ← (A₁₁+A₂₂)(B₁₁+B₂₂)
  M₂ ← (A₂₁+A₂₂)·B₁₁
  M₃ ← A₁₁·(B₁₂−B₂₂)
  M₄ ← A₂₂·(B₂₁−B₁₁)
  M₅ ← (A₁₁+A₁₂)·B₂₂
  M₆ ← (A₂₁−A₁₁)(B₁₁+B₁₂)
  M₇ ← (A₁₂−A₂₂)(B₂₁+B₂₂)
  // assemble result
  C₁₁ ← M₁+M₄−M₅+M₇
  C₁₂ ← M₃+M₅
  C₂₁ ← M₂+M₄
  C₂₂ ← M₁−M₂+M₃+M₆
  return C
Complexity

Naïve 2×2: 8 multiplications + 4 additions.


Strassen: 7 multiplications + 18 additions. Saves 1 multiply — trades arithmetic for additions which are cheaper.


Recursively on n×n blocks:
T(n) = 7·T(n/2) + O(n²)
→ O(nlog₂7) ≈ O(n2.807)
vs naïve O(n³).


For large n, the log₂7 ≈ 2.807 exponent beats 3 significantly — at n=1024 this is roughly 4.7× fewer operations.
