📐 Chinese Remainder Theorem

If m₁, m₂, …, mₙ are pairwise coprime, then for any remainders r₁, …, rₙ the system x ≡ rᵢ (mod mᵢ) has a unique solution in [0, M) where M = m₁·m₂·⋯·mₙ.

Garner's algorithm expresses x in a mixed-radix form:
x = a₀ + a₁·m₀ + a₂·m₀m₁ + ⋯
Each coefficient aᵢ is found by a short inner loop that "peels off" lower-index contributions using modular inverses.

Time: O(n² · log M) — dominated by the O(n²) modular inverse calls.

Uses: RSA / multi-prime arithmetic, fast big-integer operations, competitive programming.
