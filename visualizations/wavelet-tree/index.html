How Wavelet Tree Works

A Wavelet Tree is built over an array A[0..n−1] with values drawn from alphabet [1..σ]. Each internal node covers a value range [lo, hi] with midpoint mid = ⌊(lo+hi)/2⌋. It stores a bitmap: for each element in its sub-array, 0 if the value ≤ mid (goes left), 1 if value > mid (goes right). A prefix-sum array on the bitmap enables O(1) rank queries within any node.

  • Range Frequency — count occurrences of value v in A[l..r]: navigate down the tree, at each level transforming l and r using the bitmap prefix sums, until reaching the leaf for v.
  • Kth Smallest — find the k-th smallest value in A[l..r]: at each level count how many elements go left; if k ≤ that count descend left (k unchanged), else descend right (k decremented by left count).
  • Both queries take O(log σ) time. Construction is O(n log σ). Space is O(n log σ) bits.
